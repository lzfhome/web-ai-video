# 坤坤 · 故事视频分镜提示词（影视级）

> 蔡徐坤，一个中国大陆的明星，因被误解与封杀无法在大陆活动，远走欧美。
> 这 11 张图是粉丝所做，核心信念：**"不在低谷中离去"**。
> 别名「坤坤」谐音「鲲」；因打篮球片段走红；出走后才见其真正厉害。

**生成方式**：每张 png 作**首帧**图生视频；批量 + 勾选「尾帧衔接」，前段【段末状态】自动接后段首帧，连成长片。
**节奏档位**：中速叙事，前 3 段暗、中 4 段燃、后 3 段暖，情绪递进、不拖沓。

**全局硬锁**（每段都遵守）：
- 光影方向一致、不跳变；画面稳定不闪烁；主体（风衣男人 / 鲲 / 镇民）特征保持一致不扭曲
- 运镜平滑无抖动；镜头只为一个"情绪或动作结果"而移动，不空转
- 色调：1-4 段冷暗 → 5-6 段暗部微蓝 → 7-9 段蓝光神圣 → 10-11 段暖亮
