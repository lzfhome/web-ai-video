# Seedance 学习

## 0. 大纲

### 0.1 目标

从 0 理解 AI 视频的「调度」，不背提示词库，建立自己的「改什么 → 画面怎么变」因果表。

学完能做到：

- 看到一个镜头，能拆出景别、角度、运镜、动作、光、转场。
- 写一条提示词，知道每一句在控制什么。
- 改一个变量，能预测大概会变什么。
- 看到崩坏，能判断是提示词、时长、模型还是参考图的问题。

### 0.2 学习顺序

1. **看**：拆 3 条参考片，建立镜头词汇。
2. **拆**：把「好看」拆成可执行参数。
3. **单变量实验**：一次只改一个变量，至少 3 个变体。
4. **写结论**：事实 → 差异 → 失败 → 一句话结论。
5. **综合**：3 个镜头接成一个段落。

## 1. 我要学什么

### 1.1 调度是什么

调度不是「让画面动起来」，是**在时间轴上分配可见信息**：

- 观众在第几秒看到谁？
- 他在画面哪里？
- 他做什么？
- 镜头怎么看他？
- 动作结束后留下什么状态？
- 下一个镜头从哪个状态接？

一句话：

> 调度 = 在时间轴上安排「谁、在哪里、做什么、镜头怎么看他、下一秒从什么状态接上」。

提示词只是把调度写成模型能读的句子。

### 1.2 五个问题

写任何一条提示词前，先回答：

1. **谁**在画面里？（主体）
2. 他在**哪里**？（空间）
3. 什么在**变**？（动作/光/环境/镜头）
4. 第几秒变、**多快**、怎么结束？（时间）
5. 下一个镜头从哪个**状态**接？（衔接）

五个问题答不出来，提示词就会变成形容词堆砌。

### 1.3 调度的本质：设定不变量

> 调度 = 设定不变量 + 让一个变量变化。

- **空间不变量**：谁在左/右，什么在前/后，什么不动。
- **动作不变量**：起点姿势、受力方向、结束状态。
- **镜头不变量**：机位高度、焦距、运动起止、谁在画面中心。

不变量越多，画面越可控；变量越少，越容易看出因果。这也是单变量实验的原理。

### 1.4 十层控制面

| 层 | 控制什么 | 常用词 | 只改这一层时怎么测 | 常见坑 |
|---|---|---|---|---|
| 输入 | 模型、模式、时长、分辨率、比例、seed、音频 | 文生/图生/首尾帧/参考图 | 同一提示词换模型/模式 | 模式混用，首帧和参考图冲突 |
| 主体 | 身份、外观、服装、数量、主次 | 年龄/发型/材质/颜色/谁在前 | 同一场景换一个外观属性 | 主体太多，模型分不清谁是谁 |
| 空间 | 站位、朝向、前后景、遮挡、入画出画 | 画面左/右、前景、背景、从 A 向 B | 同一动作换左右/前后 | 写「轴线/点位」但没翻译成画面 |
| 动作 | 类型、幅度、速度、力度、起止、反应 | 走/跑/转身/挥/推/抓/停 | 同一镜头换一个动词/副词 | 5 秒塞 5 个动作 |
| 时间 | 时长、节拍、变速、升格、抽帧、循环 | 5s/10s、慢/快、急停、定格 | 同一动作换时长/速度 | 动作和时间不匹配 |
| 镜头 | 景别、角度、焦段、景深、运镜、稳定 | 远/全/中/近/特、推拉摇移跟、手持 | 同一主体换一个镜头参数 | 同时写推+拉+摇 |
| 光影 | 光位、光质、光比、色温、时间、体积光 | 顺/侧/逆/顶、硬/柔、黄金时刻 | 同一场景换光位 | 光变导致背景/肤色跳变 |
| 风格 | 写实/动画/媒介/色彩/质感 | 电影/水墨/像素/黏土/胶片 | 同一镜头换风格词 | 风格词堆太多，互相打架 |
| 衔接 | 切点、转场、首尾帧、动作/视线/方向匹配 | 硬切/叠化/遮挡/甩镜/匹配 | 两条片段换一种接法 | 上一帧糊了还拿来做首帧 |

### 1.5 镜头

| 维度 | 选项 | 效果/用途 |
|---|---|---|
| 景别 | 大远景/远景/全景/中景/近景/特写/大特写/微距 | 越大越交代空间和关系；越小越强调情绪和细节，但动作越不可读 |
| 角度 | 平视/俯视/仰视/鸟瞰/地面视角/荷兰角/过肩/主观 | 平视=客观；俯视=压迫/全局；仰视=权力/威胁；荷兰角=不安；过肩=关系；主观=代入 |
| 焦段 | 广角/标准/长焦 | 广角=空间大/透视强/边缘畸变；长焦=压缩/监视/隔离；标准=自然 |
| 景深 | 浅/深 | 浅=注意力集中；深=环境信息多 |
| 运镜 | 固定/推/拉/摇/移/跟/升降/环绕/手持/变焦/甩/穿越机 | 推=接近/压迫；拉=揭示/孤立；摇=转移注意；移=陪伴/展示；跟=代入/紧迫；升降=权力/命运；环绕=审视/包围；手持=不安/真实；固定=冷静/观察 |
| 速度 | 慢/常/快/变速/急停/回弹 | 慢=情绪/仪式；快=紧张/动作；变速=强调；急停=顿挫/危险 |
| 稳定 | 三脚架/稳定器/手持/机械臂/航拍 | 越稳越冷静；越晃越真实/不安 |

**运镜的本质**：不是「镜头动了」，是「什么保持不变，什么在变」。

- 真推：主体变大，背景也变大，透视变化，前景掠过。
- 假推：主体变大，背景不变，像贴图缩放。
- 真环绕：背景视差，主体始终在中心。
- 假环绕：主体自己转，背景不动。

### 1.6 姿势与动作

| 维度 | 选项 | 效果/用途 |
|---|---|---|
| 数量 | 1 人/2 人/3 人以上/群像 | 1 人最稳；2 人看关系；3 人以上容易崩，要写主次 |
| 姿势 | 站/坐/蹲/跪/躺/倚/背对/侧身/前倾/后仰 | 开放=自信/欢迎；封闭=防御/不安；前倾=兴趣/压迫；后仰=疏离/放松；低头=顺从/悲伤；抬头=挑战/骄傲 |
| 朝向 | 正面/侧面/背面/四分之三侧 | 正面=直接；侧面=过渡；背面=神秘/拒绝；四分之三=最像电影 |
| 视线 | 看镜头/看对手/看画外/低头/闭眼 | 看镜头=打破第四墙；看对手=关系；看画外=悬念；低头=内省 |
| 手部 | 自然下垂/插兜/抱臂/握拳/张开/拿道具 | 手是第二张脸；手部动作比表情更容易被模型画崩 |
| 重心 | 双脚平均/单脚/前脚/后脚 | 重心决定动作是否可信；转身前先移重心 |
| 动作类型 | 走/跑/跳/转身/挥手/推/拉/抓/打/倒/抱/哭/笑 | 一个镜头只选一个主动作 |
| 幅度 | 微动/小/中/大/夸张 | 小=克制/微表情；大=外放/动作戏；太大容易穿模 |
| 力度 | 轻/中/重/爆发 | 力度决定惯性、停顿和反应 |
| 起止 | 起手/过程/落点/反应 | 不写落点，模型自己编一个 |

**动作弧**：

```text
起手 → 过程 → 落点 → 反应
```

- 起手：谁先动、从哪动
- 过程：方向、速度、力度
- 落点：停在哪、手在哪、身体什么状态
- 反应：对手/环境/表情的变化

| 光质 | 硬光/柔光/体积光/丁达尔 | 硬=冲突；柔=温柔；体积=神圣/时间感 |
| 色彩 | 暖/冷/高饱和/低饱和/单色/互补 | 暖=亲密/怀旧；冷=疏离/科技；低饱和=克制/现实 |

### 1.8 时间与节奏：为什么会有 PPT 感

**PPT 感不是模型不会动，是你给的是「状态」，不是「过程」。**

模型在几个关键姿势之间插值；插值不够，就变成幻灯片。

| 现象 | 机制 | 改法 |
|---|---|---|
| 动作像幻灯片 | 你给的是离散姿势，不是连续过程 | 写一个动作弧：起手→过程→落点 |
| 动作卡顿/跳变 | 5 秒塞了多个动作 | 一个镜头一个主动作；多动作拆镜头 |
| 动作糊/抖 | 速度太快、分辨率低、镜头乱动 | 降速、升分辨率、固定镜头/稳定器 |
| 主体漂移 | 没有空间锚点 | 写左右/前后/背景参照物 |
| 背景闪烁 | 场景元素太多、光在变 | 简化背景、锁光、减少人群 |
| 脸部崩 | 近景+大动作+无参考 | 中景、固定、加参考图、减少表情幅度 |
| 肢体穿模 | 多主体接触、复杂打斗 | 拆镜头、减少接触、写清接触点 |
| 假运镜 | 只写「推/环绕」，没写不变量 | 写清主体在中心、背景视差、起止角度 |
| 结尾过冲 | 没写停点 | 写「到 X 停住」「结尾状态稳定」 |
| 动作不完整 | 时长不够 | 5 秒一个动作；延长到 10 秒 |

时间容量：

- 5 秒：一个动作弧。
- 10 秒：两个节拍，或一个动作 + 一个反应。
- 15 秒：一个小段落，最多 2–3 个动作。

速度：

- 慢：情绪、仪式、悬念。
- 常速：写实。
- 快：紧张、动作、喜剧。
- 急停：顿挫、危险。
- 变速：强调、冲击。

帧率感：

- 升格（慢动作）：情绪、细节。
- 降格（快动作）：喜剧、快节奏。
- 定格/抽帧：风格化，但容易显得卡。

### 1.9 衔接：两个镜头怎么接

模型不会「自动衔接」。两个镜头之间的连续性，是你在第二条提示词里**重新注入**的。

三个连续性：

1. **视觉连续**：同一个人、同一套衣服、同一场景、同一光位。
2. **动作连续**：A 的段末状态 = B 的段首状态。
3. **空间连续**：屏幕方向、视线、180 度轴线。

四种接法：

| 接法 | 怎么做 | 适合 |
|---|---|---|
| 首尾帧接力 | A 的最后一帧做 B 的首帧 | 同一空间、同一动作继续 |
| 干净交接帧 | 不用 A 的最后一帧，重新生成一张干净的中性帧 | A 的尾帧糊了/变形了 |
| 动作接动作 | A 停在动作中段，B 从同一中段开始，重叠 0.3–0.5 秒 | 打斗、跑、转身 |
| 匹配剪辑 | A 的形状/颜色/运动方向 = B 的相似元素 | 转场、巧思、时间跳跃 |

衔接检查表：

- [ ] A 的结尾是稳定、可读的状态吗？
- [ ] B 的第一帧和 A 的最后一帧，人物朝向一致吗？
- [ ] 屏幕方向一致吗？（A 向右走，B 还向右）
- [ ] 服装、道具、光位一致吗？
- [ ] 机位变化超过 30 度吗？（否则像跳切）
- [ ] 有没有越轴？（A 左 B 右，不要突然 A 右 B 左）
- [ ] 切点是在动作中，而不是动作结束后吗？

### 1.10 提示词骨架

```text
[景别+角度] + [主体+外观+服装] + [站位/环境] + [一个动作+方向+速度+力度] + [镜头行为：起止/速度/稳定] + [光/色/风格] + [连续性/限制/段末状态]
```

例子：

```text
中景，平视。一个穿灰色圆领上衣的短发女人站在画面左侧，身体朝右，右手拿着红色立方体。她缓慢抬起右手，把立方体举到胸前，停住，转头看向画面右侧。摄影机固定在她眼平高度，不推不拉。右侧窗户的柔光落在她脸上，背景浅灰色。5 秒，动作连续，无跳切，结尾停在她看向右侧的瞬间。
```

写完按顺序检查：

1. 景别/角度写了吗？
2. 主体在哪、朝哪？
3. 只有一个主动作吗？
4. 动作有起点、过程、落点吗？
5. 镜头有起止吗？
6. 光从哪来？
7. 结尾是什么状态？

### 1.11 工程语言 → 画面语言

模型不认「轴线」「点位」「锚点」，只认屏幕上能看见的东西。

| 工程语言 | 画面语言 |
|---|---|
| 180 度轴线锁定 | 角色 A 始终在画面左侧，角色 B 始终在画面右侧 |
| 不要越轴 | 摄影机保持在两人正前方这一侧，不切到背后 |
| A2 点位 | 角色站在茶几左侧 |
| 以沙盘为锚点 | 沙盘在画面中央，人物围绕沙盘左右分布 |
| 主轴线从门到窗 | 门在画面左后方，窗在画面右前方 |
| 接下一段 | 画面停在剑鞘从右侧切入的状态 |
| 情绪紧张 | 呼吸变浅、手指收紧、镜头不动 |

提示词里不要写：`接下一段`、`承上启下`、`A1/B2`、`轴线`、`锚点`。
要写：左/右、前/后、从哪向哪、到哪停、画面里剩下什么。

### 1.12 白名单/黑名单

- **白名单**：能稳定改变画面的词/句。
- **黑名单**：看起来有用、实际没控制力，或者有副作用的词/句。

注意：Seedance 的 API 没有独立的 negative prompt 字段。所谓「黑名单」主要是**不要写进正向提示词**，而不是写「不要 XXX」。否定句可能让模型更注意那个东西。

高控制力 vs 低控制力（待验证）：

| 高控制力 | 低控制力/有副作用 |
|---|---|
| 画面左侧/右侧、前景/背景 | 电影感、高级感、氛围感 |
| 摄影机固定在眼平高度 | 大师作品、8K、best quality |
| 从 A 向 B 缓慢推近，到 X 停住 | 推拉摇移一起写 |
| 5 秒内、动作连续、无跳切 | 先 A 然后 B 最后 C |
| 结尾停在……的状态 | 接下一段、承上启下 |
| 右手、红色、木质、湿的 | 不要多余手指、不要崩坏 |
| 顺光/侧光/逆光 | 好看、漂亮、唯美 |

这张表只是假设，必须自己测。

### 1.13 什么叫「学会了」

不是背了 100 个词，而是：

- 能预测：改 X，画面大概会怎么变。
- 能举反例：这个规则在什么条件下不成立。
- 能写出一句话规则。
- 知道这条规则的置信度：`未验证 / 已验证 / 有反例`。

## 2. 我要怎么进行实验

### 2.1 单变量实验

每课只回答一个问题，只改一个变量，至少 3 个变体。

固定：模型、模式、首帧/参考图、时长、分辨率、比例、seed、场景、动作、光。
变化：一个维度（景别/运镜/动作/速度/衔接/词）。

为什么要这样：

- 改一个变量，差异才能归因。
- 改两个变量，你看到的差异可能是第二个变量造成的。
- 固定 seed 不能保证完全复现，但能减少随机性。

### 2.4 第一课示例：景别

**问题**：景别如何改变动作可读性和情绪？

**假设**：景别越大，空间关系越清楚，动作越完整；景别越小，情绪越强，但动作越不可读。

**固定**：

- 模式：T2V
- 模型：`doubao-seedance-2-5-flash-261115`
- 时长：5 秒
- 分辨率：720p
- 比例：16:9
- seed：20261127
- 场景：浅灰色工作室，左侧高窗，右侧木门，桌上有红立方、蓝球、绿圆柱
- 主体：灰色无脸人体模型
- 动作：从画面左侧向右侧走三步，停下，转头看镜头
- 光：均匀柔和的顶光

**变量**：景别。

**提示词模板**：

```text
一间极简的浅灰色工作室，左侧是高窗，右侧是木门，中央一张低矮木桌，桌上从左到右放着红色立方体、蓝色球体和绿色圆柱体。一个灰色无脸人体模型站在桌右前方，正面朝向镜头，双臂自然下垂。{景别} 5 秒内，人偶从画面左侧向右侧走三步，停下，转头看向镜头。均匀柔和的顶光，地面有淡淡的网格线，写实摄影，画面干净，无文字。动作连续，无跳切，结尾停在人偶看向镜头的瞬间。
```

**变体**：

| 变体 | `{景别}` 替换成 |
|---|---|
| A 大远景 | 大远景，广角，人物只占画面很小一部分，强调整个房间和地面网格。 |
| B 全景 | 全景，全身，人物从头到脚完整入画，头顶和脚下留出空间。 |
| C 中景 | 中景，腰部以上，人物占据画面中央，背景仍可辨认。 |
| D 近景 | 近景，胸部以上，人物面部和肩部占满画面，背景虚化。 |
| E 特写 | 特写，面部，只有眼睛、鼻子和嘴，背景完全虚化。 |

**观察点**：

- 人物是否始终在画面内
- 走三步是否完整
- 转头是否看得见
- 背景是否漂移
- 脸有没有崩

**预判**：

- 大远景/全景：走位清楚，表情几乎没有
- 中景：动作和表情都能看到，最平衡
- 近景：转头和眼神清楚，走位消失
- 特写：只剩眼神/皮肤，走位完全消失，最容易崩

### 2.5 怎么看片

1. **第一遍**：不看提示词，完整看一遍，只记整体感觉。
2. **第二遍**：在 0%、25%、50%、75%、100% 暂停，看动作是否连贯、主体是否漂移。
3. **第三遍**：专门找失败：脸、手、边缘、背景、接触点。
4. **写事实**：不写「好看/高级」，写「第 3 秒主体占画面 60%」「转头时左耳消失」。

### 2.6 失败模式表

| 现象 | 可能原因 | 改法 |
|---|---|---|
| 像 PPT/幻灯片 | 离散状态、多动作 | 一个动作弧；拆镜头 |
| 动作跳变/瞬移 | 5 秒装太多动作 | 减动作；延长时长 |
| 动作糊/抖 | 速度太快、镜头乱动 | 降速；固定镜头/稳定器 |
| 主体漂移 | 没有空间锚点 | 写左右/前后/背景参照物 |
| 背景闪烁 | 元素太多、光在变 | 简化背景；锁光 |
| 脸崩 | 近景+大动作+无参考 | 中景；固定；参考图 |
| 手崩/多指 | 手部动作复杂 | 手放低/藏起来；减少手部特写 |
| 穿模 | 多主体接触 | 拆镜头；减少接触；写接触点 |
| 假推/假环绕 | 没写不变量 | 写主体在中心、背景视差、起止角度 |
| 结尾过冲 | 没写停点 | 写「到 X 停住」 |
| 动作不完整 | 时长不够 | 5 秒一个动作；延长到 10 秒 |
| 主体消失 | 主体太小/被遮挡 | 写画面占比；减少前景遮挡 |

### 2.7 结论怎么写

一句话，包含**条件 + 变量 + 结果**。

坏：

> 推镜很有电影感。

好：

> 5 秒 720p 下，慢推能让主体占比从 30% 到 60%，但结尾容易过冲；快推 2 秒内会糊。

结论状态：

- `未验证`：来自教程/别人的说法。
- `已验证`：自己跑过，至少 2 次一致。
- `有反例`：跑过，但不稳定/条件不成立。

### 2.8 工具：Seedance 网页 / ark.py

用 Seedance 网页时，直接复制提示词，设置：

- 模式：文生/图生/首尾帧/参考图
- 时长：5/10/15 秒
- 分辨率：720p
- 比例：16:9
- seed：固定一个数
- 首帧/参考图（如果有）

用本地 `ark.py` 时：

```powershell
python cine/image/engines/ark.py video `
  --prompt "<粘贴提示词>" `
  --out "out.mp4" `
  --duration 5 --resolution 720p --ratio 16:9 --seed 20261127
```

需要首帧：

```powershell
--first-frame "room_mannequin.png"
```

需要固定镜头：

```powershell
--camera-fixed
```

不加 `--yes` 是 dry-run，只打印计划，不花钱；确认后加 `--yes`。

### 2.9 资料怎么用

- 教程是字典，不是课程。不要通读。
- 带着问题找：`运镜`、`轴线`、`转场`、`失败`、`打斗`。
- 只抄「可执行句」，例如「摄影机固定在两人正前方眼平中景，不推拉不摇移」。
- 每条摘录标 `未验证`；自己跑过再升级。
- 不要抄「电影感」「高级感」这种没有控制力的词。

### 2.10 一课完成的标志

- 生成了 3–5 条片段。
- 记录了事实、差异、失败。
- 写出一句话结论。
- 标了状态。
- 能预测下一个类似镜头会怎样。

如果做不到最后一条，换一个 seed 再跑一次；还是不行，就说明这一课还没看懂。
