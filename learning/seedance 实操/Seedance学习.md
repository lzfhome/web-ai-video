# Seedance 基础学习

## 目标

从 0 理解 AI 视频的「调度」，不背提示词库，建立自己的「改什么 → 画面怎么变」因果表。

学完能做到：

- 看到一个镜头，能拆出景别、角度、运镜、动作、光、转场。
- 对比两段提示词和参考帧，可以知道两者的镜头/动作/剧情内容要如何衔接。
- 写一条提示词，知道每一句在控制什么。
- 改一个变量，能预测大概会变什么。
- 看到崩坏，能判断是提示词、时长、模型还是参考图的问题。

## 元素

一段视频有很多元素。每个元素是一级变量，下面才是能单独做实验的二级变量。

建议顺序：1 → 2 → 3 → 4 → 5 → 6，先把调度链路跑通；7–12 做补强。

### 1. 输入条件

| 二级变量 | 取值 | 主要影响 | 实验示例 |
|---|---|---|---|
| 生成模式 | 文生 / 图生-首帧 / 图生-首尾帧 / 全模态参考 | 自由度、构图锁定、一致性 | 同一提示词换模式 |
| 模型版本 | Seedance 2.5 / 2.5 flash / 2.0 / 2.0 fast / 2.0 mini | 画质、动作、稳定性 | 同一提示词跑 3 个模型 |
| 时长 | 4–30s（2.5）/ 4–15s（2.0）/ -1（自动） | 动作容量、节奏 | 同一动作改时长 |
| 分辨率 | 480p / 720p / 1080p / 4K（2.5 flash、2.0 fast/mini 最高 720p） | 细节、崩坏率 | 同一提示词改分辨率 |
| 比例 | 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 / adaptive | 构图、平台适配 | 同一提示词改比例 |
| 音频 | 开 / 关（API 默认开；本地 ark.py 默认关） | 环境声、对白 | 同一提示词开关音频 |

> `seed` 和 `camera_fixed` 不在官方 API 文档的参数列表里；本地 `ark.py` 有传，但不要把它们当可靠控制。详见「Seedance 模型习惯」。

## Seedance 模型习惯

> 这一章不是「元素」，是工具层：API 允许什么、模型偏好什么、哪些词有效/无效、怎么崩。
> 以火山方舟官方文档为准；标「经验」的才是还没被官方或实验确认的。

### API 允许什么（官方）

| 项目 | 官方规则 |
|---|---|
| 模型 ID | 2.5 `doubao-seedance-2-5-260628`；2.5 flash `doubao-seedance-2-5-flash-261115`；2.0 `doubao-seedance-2-0-260128`；2.0 fast `doubao-seedance-2-0-fast-260128`；2.0 mini `doubao-seedance-2-0-mini-260615` |
| 任务类型 | 文生；图生-首帧；图生-首尾帧；全模态参考（参考生视频 / 编辑 / 延长） |
| 任务类型引导 | `omni_reference_task_type`：`auto`（默认）/ `reference` / `edit` / `extend`；`edit` 要求 `duration=-1`、`ratio=adaptive`、参考视频 4–30s；`extend` 要求 `ratio=adaptive` |
| 互斥 | 首帧、首尾帧、全模态参考是 3 种互斥场景，不能混用 |
| 首帧/首尾帧 | 2.5 必须 `ratio=adaptive`；2.0 可指定比例或 adaptive |
| 首尾帧画幅 | 官方两处说法不完全一致：API 参考说尾帧自动裁剪适配，提示词指南说会被拉伸。最稳的是输入同画幅首尾帧 |
| 时长 | 2.5：4–30s 或 -1；2.0：4–15s 或 -1 |
| 分辨率 | 2.5：480p/720p/1080p/4K；2.5 flash：480p/720p；2.0：480p/720p/1080p/4K；2.0 fast/mini：480p/720p |
| 比例 | 21:9 / 16:9 / 4:3 / 1:1 / 3:4 / 9:16 / adaptive |
| 参考素材上限 | 2.5：30 图 + 10 视频 + 10 音频；2.5 flash：10 + 5 + 5；2.0：9 + 3 + 3 |
| 参考视频/音频时长 | 2.5：单段 2–30s，总 30s；2.0：单段 2–15s，总 15s；2.5 视频编辑输入 4–30s |
| 音频参考 | 2.5 可单独传音频；2.0 必须搭配至少 1 个图片或视频 |
| 有声视频 | API 默认 `generate_audio=true`；本地 `ark.py` 默认关 |
| 水印 | 默认 `false` |
| 尾帧 | `return_last_frame=true` 可取尾帧，适合做首尾帧接力 |
| 样片模式 | 只有 2.5 支持；只能 480p |
| 输出格式 | 2.5 支持 mp4/mov；2.0 只有 mp4 |
| 提示词长度 | 中文 ≤500 字，英文 ≤1000 词 |
| 真人人脸 | 不支持直接上传含真人人脸的参考图/视频；用授权素材、虚拟人像或本账号模型产物 |

### 本地脚本 vs 官方 API

本地 `cine/image/engines/ark.py` 还会传 `seed` 和 `camera_fixed`，但**官方 API 文档的参数列表里没有这两个字段**。它们可能是历史参数、被忽略，或者只是脚本层的封装。不要把它们当可靠控制；要用就先做 A/B 验证。

### 提示词偏好（官方）

- 正向描述优先。
- 官方明确支持负向控制**字幕和音频**：`不要字幕`、`无 bgm，只生成环境音和动作音`、`不要任何声音`。
- 2.5 响应整数秒时间戳；2.0 只响应镜头序号，不响应时间戳。
- 2.5 支持多视图主体参考；2.0 不建议。
- 热门运镜可以直接写；小众运镜写「名词 + 描述性解释」。
- 转场写清触发点、方式、时间。
- 动作写概括性描述，少重复细节；表情写描述性语句，少用成语。
- 多素材逐一绑定编号和用途。

### 黑名单

| 词/句 | 问题 | 状态 |
|---|---|---|
| 电影感、高级感、氛围感 | 没有可验证的控制力，容易变成风格碰运气 | 经验 |
| 大师作品、8K、best quality | 不是参数，不改变调度 | 经验 |
| 推拉摇移一起写 | 镜头行为冲突 | 经验 |
| 先 A 然后 B 最后 C | 多动作容易 PPT/跳变 | 经验 |
| 接下一段、承上启下 | 管理语言，模型不认 | 经验 |
| 不要多余手指、不要崩坏 | 官方只明确支持字幕/音频负向控制；视觉负向控制不保证 | 官方边界 |

注意：官方没有独立的 `negative_prompt` 参数；负向控制写在提示词里，但只对字幕/音频有明确支持。

### 模型差异（官方）

| 模型 | 时长 | 分辨率 | 参考素材 | 备注 |
|---|---|---|---|---|
| Seedance 2.5 | 4–30s | 480p/720p/1080p/4K | 30 图 + 10 视频 + 10 音频 | 样片模式、mov、多视图、时间戳、任意比例 |
| Seedance 2.5 flash | 4–30s | 480p/720p | 10 + 5 + 5 | 无样片模式 |
| Seedance 2.0 | 4–15s | 480p/720p/1080p/4K | 9 + 3 + 3 | 音频需搭配图片/视频；不响应时间戳；6 档固定比例 + adaptive |
| Seedance 2.0 fast | 4–15s | 480p/720p | 9 + 3 + 3 | 同上 |
| Seedance 2.0 mini | 4–15s | 480p/720p | 9 + 3 + 3 | 同上 |

补充：2.5 与 2.0 的美学风格差异明显；混用可能不连贯。需要保留 2.0 风格时，官方建议把 2.0 视频作为延长输入，输出 MOV。

### 失败习惯（经验，不是官方 API 规则）

| 现象 | 可能原因 | 改法 |
|---|---|---|
| 崩脸 | 近景 + 大动作 + 无参考 | 中景、固定、加参考图 |
| 手崩 / 多指 | 手部动作复杂 | 手放低 / 藏起来，减少特写 |
| 穿模 | 多主体接触 | 拆镜头、减少接触、写接触点 |
| 闪烁 | 元素太多、光在变 | 简化背景、锁光 |
| 漂移 | 没有空间锚点 | 写左右 / 前后 / 背景参照物 |
| 假运镜 | 没写不变量 | 写主体在中心、背景视差、起止角度 |
| PPT 感 | 离散状态、多动作 | 一个动作弧、拆镜头 |
| 过冲 | 没写停点 | 写「到 X 停住」 |
| 动作不完整 | 时长不够 | 5 秒一个动作，延长到 10 秒 |
| 主体消失 | 主体太小 / 被遮挡 | 写画面占比、减少前景遮挡 |
| 多主体混淆 | 主体太多、主次不清 | 减到 2 人、写谁在前 / 谁在左 |
