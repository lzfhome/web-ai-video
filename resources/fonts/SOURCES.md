# 字体来源

字体文件不入库（每台机器本地保留），需要时按下面来源下载到本目录。

| 文件 | 来源 |
|---|---|
| `NotoSansSC-VF.ttf` | https://fonts.google.com/noto/specimen/Noto+Sans+SC （或 https://github.com/notofonts/noto-cjk/releases） |
| `Geist-VF.ttf` | https://vercel.com/font |
| `GeistMono-VF.ttf` | https://vercel.com/font |

`skills/ai-teardown/engine/assets/fonts/` 下的字体（Noto / Geist / LXGW WenKai）同样不入库：

- LXGW WenKai：https://github.com/lxgw/LxgwWenKai/releases

缺字体时渲染会回退系统字体；LXGW 缺省回退楷体。
