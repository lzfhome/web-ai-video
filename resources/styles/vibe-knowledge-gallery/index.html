怎么开口

只给选题

「做一期乌江亭长」——推荐 3 套风格（推荐第一的排第一，附理由和风格图），你挑一套。

点名风格

「用水墨纸本做一期王安石变法」——直接按这套风格开工。

改成自己的风格

「把古风改成我的品牌色」或「从空白做一个黑板粉笔风」——一题一问定方案，出并排风格图和 15–30 秒 demo，你点头才存成「我的风格」。

两档

基础档 · 0 积分

标「增强档」以外的风格都能做。代码画面（Opus 手写插画 + 动效）、小米 MiMo 配音、曲库配乐、earshot 代码音效。

增强档 · 按镜头挑

只把写实场景和最需要被记住的 1–3 个时刻交给 Renoise（配图 / 动态镜头 / 定制配乐 / 音效）。轻 ≈25–40、标准 ≈250–300、旗舰 ≈600–700 积分，每次先报价、你确认才生成。

6 种母版

  • A 猜谜概念片（抽象概念：先让观众猜，再命名概念）
  • B 两难选择片（历史 / 实验：换你，你怎么选）
  • C 痛点原理片（日常反常 × 冷门原理，竖屏友好）
  • D 一条主线片（碎片串成一条线：技术史、学科全貌）
  • E 闯关片（题型 / 方法论：一关一招，秘籍总表）
  • F 六面轮转片（一个问题六种答案，45 秒）

每期流程

① 选题 + 母版 + 风格 + 档位 → ② 事实清单（每条对原文）→ ③ 旁白稿 + 独立审稿 → ④ 分镜 / 报价 → ⑤ 开场试听定音色语速 → ⑥ 配音、画面、渲染 → ⑦ 质检（文字回读核对事实、响度）→ ⑧ 发布包（标题、话题、两张封面）。
