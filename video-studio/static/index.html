视频延长（续写）

添加「参考视频」，任务类型选「视频延长」，提示词写 延长 / 续写 / 延续。

示例：向后延长 示例：续写前5秒

视频编辑

添加「参考视频」，任务类型选「视频编辑」，提示词写 编辑 / 加上 / 删掉 / 替换。

示例：增加物体 示例：替换主体 示例：删除音乐

编辑/延长任务会自动锁定 ratio=adaptive、时长=智能(-1)。点击示例自动填入提示词。
