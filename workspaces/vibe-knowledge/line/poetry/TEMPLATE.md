# poetry 模板（Agent 操作手册）

这条产线只做一件事：**书封 + 引文卡片 + 逐字出现 + BGM**。  
无论 6 场、8 场还是 12 场，流程一样。

## 输入只有四样

| 变量 | 说明 |
|---|---|
| 题材 | 标题、书名、作者、出版社、册数 |
| 封面 | 每场一张；没给就按书名自动抓（默认） |
| BGM | 一个音频文件 |
| 内容 | 每场的句子、类型、署名、章节、上下文、marks、小传 |

时间、字号、黑边、特效、停留、转场全部由 `defaults.json` 决定，**不要改**。

## 三个状态（2026-11-18 新增）

| 状态 | 产物 | 说明 |
|---|---|---|
| 定稿 | `selection-*.md` | 句子、章名、封面、顺序定了；不是渲染输入 |
| work.json | `<lesson>/work.json` | 渲染器输入；定稿必须落到这里 |
| 成片 | `build/deliver/` | 渲染 + 交付后才存在 |

- 只有 selection md 不算做完；必须写 `work.json`。
- 删掉 `build/` 后，项目回到 work.json 状态；不要拿旧片当新定稿。
- 更新已有项目不要反复 `project.py build --name <同名>`：`_unique_dir` 会生成 `-v2/-v3`。用 `compose.py` 覆盖 canonical 的 `poem.json`，或先确认输出目录。

## 内容规则（强制）

1. **封面与中心句解耦**：封面只作展示，不要求中心句出自该册。底部封面行写 `封面：第X册 册名 · 出版社`（原书用“卷”就写 `卷X 卷名`）；册名以封面为准，不能自己编。**原书没有独立册名、封面只印编号时，只写 `第X册`，不要自己编**；如《诛仙》8 册。
2. **封面按用户选定版本，整套统一**：同一套封面必须来自同一版，不能卷一用长江、卷四用百花洲。选哪版只影响封面，不影响选句；文本源可以用最新电子版。
3. **一册一个人物、一句话；同一人物最多 2 场，且不能连着出现**。不要让一部书 4/6 场都写同一个人；人物要分散到不同册、不同阵营。主角允许在首尾各出现一次。
4. **对白优先，好的旁白也可用**：能从原文找到“某人道：……”就用对白；如果旁白/描述本身足够好（境界体系、世界观、名场面），可以直接做中心句，`type` 标 `narration`，不硬安人名，也不要把旁白伪装成对白。**选句时对白、旁白同时找，不要只列对白。**
5. **说话人必须来自原文**，查不到就标旁白，不要硬安名字。
6. **指定回避的人物不得出现**（例如本书明确不要沧月）。
7. **章节行与封面解耦**：`source` 写“第X章 章名”（序章写“序章 章名”），章名来自文本源，不写“第X卷”；不再要求这句出自当前封面那一册。句子按故事顺序从头到尾排，封面按册序 1→N 播，两条线并行、不互相证明。`compose.py` 会校验 `source` 含“第X章”或“序章”，只写册名直接报错。
8. **章节行按诛仙版式**：显示在署名下方，跟在台词之后出现，一行“第X章 章名”；字号 18，不要放大成标题，也不要拆成“册名 + 章名”两行。参照诛仙项目 `projects/zhuxian-eight/`（旧成片已删，按 work.json 重渲染）。
9. **`bio` 是作者小传，不是剧情简介**：每段写作者的生平、写作经历、作品谱系；至少一半场次是长段（≥40 字），其余可以短。**不要写本场人物、本场情节或小说内容**；`footer4` 显示的就是这段（前面加 `生平：`）。
10. **中心句先看读者热度，再回原文**：按 [`SOURCES.md`](SOURCES.md) 的源和硬规则选句，**默认只用免登录渠道**；至少两个来源指向同一句、同一人物或同一场面。查不到就写明“无平台热度数据”，不要编造。平台热度只用来选句，章节必须回到最早实体版目录核对。
11. **台词场只写台词**：不要写“某某道：”“某某叹道：”“某某沉默片刻……”这类前置；署名靠下方 `——人物`，正文只留引号里的内容。**旁白场只写旁白**，不署名、不加引号，不要为了凑人物把旁白伪装成台词。
12. **中心句与热度源要能逐场列出**：每个题材交付时，必须能列出「场次 / 册 / 人物 / 中心句 / 出处 / 热度源 / 判定」。热度判定只有三种：双源 ✅、单源 ⚠、编辑选择 ○；不允许把编辑选择写成热句。
13. **一个项目只用一个文本源**：句子和章名同源。平台热度只用于选句，不改定稿文字；定稿源没有章名就留空，不跨版补。两个版本有差异时，先列差异让用户选；不要用 A 版句子配 B 版章名。

## 主线与感情比例（强制）

### 先写主线，再选句

每个题材动笔前，先写一句主线。例：

- 《紫川》：三兄弟在乱世中的情义、权力与分裂。
- 《悟空传》：自由、命运与不肯低头。
- 《网游之纵横天下》：游戏里的兄弟、成长和普通人的那点幸福。

选句必须服务这条主线。只戳情绪、和主线无关的句子，热度再高也不选。

### 感情内容最多 50%

- **感情类（只指爱情/romance）**：爱情、CP、告白、思念、吃醋、虐恋。
- **按场次计**，台词 + 旁白合计，感情类 **最多 50%**。
- 6 场最多 3 场感情；7 场最多 3 场；8 场最多 4 场；5 场最多 2 场。
- **50% 是上限，不是目标。** 如果书本身感情线很轻，比例应该更低。
- 其余 50% 必须给：主线、世界观、群像、战斗、命运、成长、幽默、时代背景等。
- “兄弟情、亲情、家国”不算感情类，**全部按主线判断**；只有爱情线才计入 50%。如果整部片子全是各种关系纠葛，仍然算感情过重。
- **感情比例和旁白比例是两套账**：旁白 ≤50% 看的是台词/旁白，感情 ≤50% 看的是内容分类，互不替代。

### 标注与验收

每场在 `context` 开头标一个分类：

```text
[主线] / [感情] / [世界观] / [群像] / [其他]
```

notes 里汇总：

```text
主线 3 / 感情 3 / 世界观 0 → 感情 50%
```

交付前必须核对：**感情类 ≤ 50%**。

## 出场节奏（固定，2026-11-15 定稿）

| 项 | 值 | 说明 |
|---|---|---|
| 多行（≥2 行） | **2.3 秒/行**，淡入 **1.0 秒** | 一行一行出，不算字数 |
| 单行 | **0.4 秒/字** | 逐字出现 |
| 署名 + 章节 | 中心句最后一个字出现后 **2.0 秒** | 两个同时出，章节在署名下方一行 |
| 场景停留（署名后） | `per_sec 0.5`、`min 5.0s`、`max 8.0s` | 按中心句时长缩放 |
| 最后一场 | 署名后**固定停 12 秒** | 不受字数与 max 限制 |
| 转场 | 0.95 秒 | 不动 |

- 值写在 `defaults.json` 的 `timing.after`；`poem.json` 会同步一份，渲染时以 `poem.json` 为准。
- 实际时长由 `render.py` 写进 `build/timings.json`；**改完时间必须先看 timings.json 的数字**，浏览器会缓存 `poetry.js`，别拿旧片子当新版。
- 参考节奏：`projects/piaomiao-seven/` 的 work.json（7 场 109.8s，B01 16.35s、B07 26.35s）。

## 选句与分册（2026-11-15 定稿）

1. **旁白权重**：旁白 **≤50%**（目标约 50%；13 场最多 6 场旁白，11 场最多 5 场）；先找旁白，但不能超过一半。
2. **卡数跟着热点走**：一册可以 1 句，也可以多句；**按这一册实际有多少合格热点句来定**，不要求每册 2 张或 3 张，也不要用弱句凑数。同一册人物尽量不重复。**主角全片卡片占比 ≤30%**：主角卡数 ÷ 全片总卡数（旁白卡 + 台词卡），单卡场景算 1 张，多卡场景每张都算；配角、群像、旁白要占剩下的 ≥70%。多主角题材按每个主角分别算，除非用户另定合计上限。
3. **台词/旁白交错**：只看连续性，**不规定开头**。按全片卡片顺序，同类型连续最多 2 张；不要出现 3 张以上连续旁白或连续台词。可以从台词开始，也可以从旁白开始。**单卡场景算 1 张，多卡场景每张卡都算；场与场之间不重新计数。** 示例只是示例，不是固定模板：`旁白-旁白-台词-台词-旁白-台词-台词-旁白` 和 `台词-旁白-台词-台词-旁白-旁白-台词-台词-旁白` 都合格。
4. **热度至少两个独立来源**才算 ✅；只有一个标“单一来源”，一个都没有标“编辑选择”，**不要写成热句**。
5. **分册必须核对**：豆瓣各册（后几册可能是单独条目、书名不带册号）+ 孔网套装标题 + 出版社时间；不要按第一轮搜到的册数就定。
6. **章节行只写“第X章 章名”，不写“X卷”**；卷名、册名只出现在倒数第二行 footer。**如果无法确认具体章节，可以不写章节行（`source` 留空），只保留册名/册号**；但必须在 `context` 或 notes 标注“仅册级核对”，不能编章节。
7. **末场文字不超过 4 行**，避免压到作者小传；长句先删到能独立成立的短句。
8. **封面只等比裁切，不拉伸**。优先级：豆瓣初版 > 京东/淘宝原图（百度图片 `data-show-ext` 里的 `objurl`）> 孔网实拍（裁掉底部水印）。
9. **极端情况才让中心句压过顺序**：
   - 默认先守规则，不要因为“某句更好”就自动改顺序、卡数或单/多卡结构。
   - 发现多个好中心句，或好句与规则冲突：**先列候选和可行方案，让用户选**，不要替用户决定。
   - 只有在用户确认“没有合规解”，或明确授权按中心句走时，才放宽卡数/交错/人物分布；这时顺序可以完全不管，连续 3 张以上同类也可以。
   - **硬规则不能让**：原文不改、不跨册借句、不编热度、不用弱句凑数。

## 开题流程（先候选，后确认）

1. **先按册找候选**：每册尽量列全你认为合格的中心句，写原文、人物/旁白、章节、热度、类型（台词/旁白）。宁可多列，不要先替用户筛掉。
2. **再给结构建议**：按候选给出每册 1 卡还是多卡、卡数、全片顺序的建议；可以给 2–3 个可行方案。
3. **让用户选**：中心句、单卡/多卡、卡数、顺序，由用户定；给选项时用可点击选项。
4. **确认后再 compose/render**：用户没确认前，不把候选定成最终 `work.json`，也不渲染。
5. 只有用户确认“规则内确实没有合适解”时，才启用第 9 条的极端情况。

## 排版（固定）

| 项 | 规则 |
|---|---|
| 自动字号 | 1 行 70 / 2 行 58 / 3 行 52 / 4 行 46 / 5 行 42 |
| 6–7 行 | 自动字号会压到底部小传，必须手写 `type_size`（44 或 42） |
| 单场上限 | **最多 7 行**；超过就删句或换句，不要硬塞 |
| 每行长度 | **行内断句只能在标点（，。！？；）后**，不准把一句话从中间切开。**整句的最后一行可以没有标点**（原文本就没有句末标点）。长度尽量 ≤20 字，标点句可略长 |
| 署名 | 台词一行 `——人物`；旁白不署名 |
| 章节 | 署名下方一行，18 号；“第X章 章名”，不写“X卷” |
| 底部 | 倒数第二行册名，最后一行作者小传；文字块不得压到这两行 |

长句示例（7 行、54–64 字）：`type_size: 44` 后文字底边约在画面 78%，仍在 footer 之上。

字段名是 `type_size`（不是 `type`）：`type` 只能是 `dialogue / narration / citation`，写成对象会直接报错。

## 单卡 / 多卡场景（按场景切换，固定）

`cards` 是按**单个场景**生效的，不是整支片子一个模式：

- `cards` 只有 **1 张** → 回退旧单句模式：逐字或逐行出现、署名延迟 2s、按旧规则停留；
- `cards` **2 张及以上** → 多卡模式：文字整块淡入/淡出，只换文字块和作者小传。

同一支片可以混用。例如第 1 册 1 张、第 2 册 3 张、第 3 册 1 张，成片就是 **旧模式 / 多卡模式 / 旧模式**，不是全片统一成一种。

### 多卡模式（2 张及以上）

1. **一张卡 = 一句中心句**；仍然按“一卡一人物/旁白”，人物尽量不重复。
2. **每册卡数不固定**：不是每册 2 张，也不是每册 3 张，而是**按这一册实际有多少合格的热点句来定**。
   - 有 2 句热点就做 2 张；
   - 有 3 句就做 3 张；
   - 有 5–6 句就做 5–6 张；
   - 没有合格热点句，可以只做 1 张（走旧单句模式）、少做，甚至不做这一册；**不要用弱句硬凑数**。
3. 单册建议 **1–6 张**；超过 6–8 张考虑拆成上下部，或单独做一支。
4. 整部片子各册卡数可以不一样，**不要为了整齐强行拉平**。
5. 旁白 ≤50%、感情 ≤50% 的规则不变，按整册所有卡合计。
6. 多卡场景的文字整块出现，不逐字、不逐行；章节、署名、封面/说明/作者/生平跟中心句同一张卡一起出现。
7. 卡时长：
   ```text
   hold = max(3.5, 字数 × 0.20 + 1.2) + 2 × card_fade
   最后一张再 +1.5
   ```
8. `card_fade` 是单侧淡入/淡出秒数，只作用于多卡场景：
   - `1.0` → 淡出 1s + 淡入 1s，总 2s
   - `1.5` → 淡出 1.5s + 淡入 1.5s，总 3s
9. 卡间不重叠文字：前一张完全淡出后，后一张才开始淡入；中间可以有一小段只有封面。
10. `footer`（封面：第X册 册名 · 出版社）、`footer2`（说明）、`footer3`（作者）固定不动；`footer4`（生平）每卡一段。
11. 单卡场景在 `compose.py` 里会转成旧 `lines` 场景，`poem.json` 不再保留 `cards`，确保走旧模式。

示例（2 张卡，多卡模式）：

```json
{
  "cover": "img/cover-1.jpg",
  "palette": "moon",
  "header": "VOL. I",
  "footer": "封面：第1册 册名 · 出版社",
  "card_fade": 1.0,
  "cards": [
    {
      "lines": ["第一句，", "第二行。"],
      "type": "narration",
      "source": "第三章 章名",
      "bio": "作者小传……",
      "category": "[主线]"
    },
    {
      "lines": ["第二句。"],

```

## 底部四行（固定）

每张卡底部固定四行：

```text
封面：第X册 册名 · 出版社
说明：句子取自电子书版，与封面非同一版本，无册次对应关系；封面仅作展示，原文已核。
作者：作者名
生平：一句话作者小传
```

1. **封面与中心句解耦**：封面只作展示，不要求中心句出自该册。句子按故事顺序排，封面按册序播，两条线并行。
2. **封面行**：`封面：第X册 册名 · 出版社`；册名只写封面上真实有的名字，没有就不编，只写 `第X册`。
   **有册写册，有卷写卷**：封面写 `第X册` 就写 `第X册`，封面写 `卷X` 就写 `卷X`；用字跟封面一致（封面是 `卷壹` 就写 `卷壹`，不要改成 `卷一`）。
3. **说明行**：固定文案，不改。
4. **作者行**：只写名字。
5. **生平行**：作者小传，不是剧情。
6. **多部作品合在一个片子里，各自从第 1 册/卷壹重新编号**，不要 6 册接 6 册再接 5 册写成 1–17。
7. 册名和编号必须回封面核对；不能按“应该是第几本”猜。

例：

- `封面：第1册 天机卷 · 团结出版社`
- `封面：第1册 · 重庆出版社`（封面只有 Ⅰ–Ⅵ，没有册名，不编）
- `封面：卷壹 洪武天下 · 长江出版社`

## 断句（固定）

1. **只能在标点后断**：`，` `。` `！` `？` `；` `：` `、` `……`。  
2. **除整句最后一行外，每行必须以标点结尾**；行首不能是标点。  
3. **整句最后一行可以没有标点**，因为句子本身已经结束；《前辈的东西好大哦》就是合规的。  
4. **一行可以包含多个分句**；不准在一个分句中间切开，例如“哦，我忘了 / 魔头是无法进去的”不合规，因为第一行没标点。  
5. **不增删文字、不改标点**，只决定断点；原文没有句末标点时，最后一行保持原样。  
6. **优先每行 ≤20 字**；但标点分句本身超过 20 字时，保留整句并降低 `type_size`，不要从中间切。  
7. **单场 ≤7 行**；6–7 行手写 `type_size: 44` 或 42。  
8. 引号、括号不单独成行；行首不能是 `，。！？；：、`。

## BGM 前奏裁剪（固定）

**片头只留 1.2s 静音过渡；源曲前面多余的静音要裁掉，不要补静音。**

1. 测正拍：  
   `python cine/audio/tools/bgm_lead.py <音频> --keep 1.2`
2. 按输出写 `work.json`：  
   ```json
   "bgm_from": 3.3,
   "bgm_fade_in": 0.1
   ```
   - 正拍 4.5s → `bgm_from: 3.3`（4.5 − 1.2）
   - 正拍 ≤1.2s → 不裁，`bgm_from` 省略或写 0
   - `bgm_from` 是“跳过源曲前 N 秒”，不是“在片头加 N 秒静音”
3. 重建：`compose.py` → `retime.py` → `project.py render`
4. 验收：前 1.2s 应 ≤ −55 dB（听感静音），1.2s 后明显有音乐；不要用 `bgm_at` 补静音，该字段已移除。

实例：小兵传奇 `bgm_from: 3.3`，源曲 4.5s 正拍，片头留 1.2s。
