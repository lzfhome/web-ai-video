## 共同约定

- 每个项目只保留一个 `work.json`、一个 `poem.json`、一套 `assets/`。
- `work.json` 的 `covers` / `bgm` 不带 `assets/` 前缀；渲染器会自动拼 `./assets/`。
- 封面不足时按册序重复，不留空册；紫川 8 册封面配 9 张卡，第1册用两次。
- 句子和章名同源；不再用平台热度改定稿文字，也不跨版补章名。

## 复刻命令

```powershell
python project.py render <slug> --line poetry --workers 2
python project.py deliver <slug> --title "<片名>" --poster 9
```

`slug` 就是 `projects/<slug>/` 的名字。渲染前确认：

1. `project.json` 的 `line` 是 `poetry`；
2. `work.json` 的 `covers` / `bgm` 不带 `assets/` 前缀；
3. 6–7 行的场写了 `type_size`；
4. 章节行没有“卷”；
5. 项目里没有旧 `mp4`，`deliveries/` 是空的。
